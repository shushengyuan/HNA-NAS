# 🚀 HNA-NAS

## 📖 Introduction

This project proposes an efficient **Neural Architecture Search (NAS)** method tailored for edge devices, successfully bridging the gap between algorithmic design and practical hardware deployment. 

---

## 🎥 Deployment Demonstrations

We have conducted real-world inference benchmarks on three mainstream edge computing platforms: **NVIDIA Jetson AGX**, **Ascend 310B**, and **Ascend 310P**.

For each device, we demonstrate two distinct model architectures generated by our NAS framework:
* 🏎️ `gpu-model`: Optimized for GPU/Accelerator latency.
* 🧠 `cpu-model`: Optimized for CPU latency.
